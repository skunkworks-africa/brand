3 resources

Filter rows locally or sort by resource name. The sorting and filtering hooks are documentation demonstrations; integrate your own data source.

Code

<div class="sk-field"><label for="table-filter">Filter resources</label><input class="sk-input" id="table-filter" type="search" placeholder="Try tokens or styles"></div><div class="sk-table-wrap" tabindex="0" role="region" aria-label="Scrollable table"><table class="sk-table" id="example-table"><caption>Design resources</caption><thead><tr><th scope="col"><button class="sort-button" id="table-sort" type="button">Resource <span aria-hidden="true">↕</span></button></th><th scope="col">Format</th><th scope="col">Status</th></tr></thead><tbody><tr><th scope="row">Component styles</th><td>CSS</td><td>Available</td></tr><tr><th scope="row">Design tokens</th><td>JSON / CSS</td><td>Available</td></tr><tr><th scope="row">Interaction scripts</th><td>JavaScript</td><td>Available</td></tr></tbody></table></div><p id="table-status" role="status">3 resources</p>

Usage

  • Use table captions and header scopes. Preserve row and column relationships.
  • Place aria-sort on the currently sorted column header.
  • Keep the filter label visible and provide a zero-results message.
  • On small screens, scroll the table container instead of the whole page.
  • For large datasets, provide server-side filtering and pagination with announced loading states.
